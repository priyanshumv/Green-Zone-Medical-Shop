# 🌿 Green Zone - Eco-Friendly Medical Shop

![Green Zone Banner](assets/logo1.jpg)

A modern, responsive e-commerce website for a neighbourhood medical shop with an eco-friendly approach. Built with HTML, CSS, Bootstrap, and Vanilla JavaScript.


### 🛒 Shopping Experience
- **Product Catalog**: Browse through a wide range of medicines and healthcare products
- **Shopping Cart**: Add/remove items with real-time price calculations
- **Checkout System**: Complete order placement with customer details
- **Search Functionality**: Quick product search with suggestions

### 🎨 Design & UI
- **Responsive Design**: Optimized for mobile, tablet, and desktop
- **Modern Aesthetics**: Green theme with smooth gradients and animations
- **Interactive Elements**: Hover effects, transitions, and loading states
- **Accessible**: Following web accessibility best practices

### 🌍 Eco-Friendly Focus
- Sustainable design philosophy
- Green color scheme representing environmental care
- Focus on recyclable packaging messaging
- Community-oriented approach

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Framework**: Bootstrap 5.3.2
- **Storage**: LocalStorage API for cart persistence
- **CDN**: Bootstrap, Font integrations
- **Backend**: server
- **Icons**: Unicode
- emoji for lightweight design

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local server (optional, for development)

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/green-zone.git
cd green-zone
```

2. Open the project
- Simply open `index.html` in your web browser
- Or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js http-server
npx http-server
```

3. Visit `http://localhost:8000` in your browser

## 💻 Usage

1. **Browse Products**: Navigate through the product catalog on the home page
2. **Add to Cart**: Click "Add to Cart" buttons to add items
3. **View Cart**: Check your cart at any time from the navigation
4. **Checkout**: Complete your order with shipping details
5. **Contact**: Use the contact form for inquiries
